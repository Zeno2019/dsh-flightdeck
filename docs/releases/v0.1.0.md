# DSH Flightdeck v0.1.0

## English

**Full changelog:** First stable release — promotes the RC.9 build to stable with no functional changes; the repository is open-sourced under Apache-2.0.

- Bundled DSH core: `0.1.0-rc.7` (unchanged)
- Assets: `dsh-flightdeck-0.1.0-dsh-0.1.0-rc.7-windows-x64-setup.exe`, `dsh-flightdeck-0.1.0-dsh-0.1.0-rc.7-mac-arm64.dmg`
- Packages are unsigned; see the README for SmartScreen/Gatekeeper handling. Do not disable Gatekeeper globally. Release testing is limited to installation, startup, and HTTP readiness on Windows x64 and macOS arm64.
